tinyAGENTS← Open your office

Install. Say hello. Move in.

Install the plugin, approve your computer in the browser, then get back to coding. Your office is created automatically. No file downloads, repository clone or separate pairing command.

1. Install your plugin

Run the commands for your coding app in a terminal. You need Node.js 22.18+ on that app’s PATH.

Codex

codex plugin marketplace add michaelraim/tinyagents
codex plugin add sidequest-office@tinyagents

Restart Codex. Enable the plugin and review/trust its hooks in /hooks. Use the plugin’s setup action or start a new session. If your Codex version has no plugin commands, update it first.

Claude Code

claude plugin marketplace add michaelraim/tinyagents
claude plugin install sidequest-office@tinyagents --scope user

Restart Claude Code, enable its plugin hooks and start a new session.

2. Say hello in your browser

The plugin opens tinyAGENTS automatically. Sign in with GitHub or GitLab if needed. Check the computer name and click Connect this computer. Wait for You’re home. That’s the whole connection process.

Your existing office is used automatically. If you’re new, we create one with your computer’s time zone. Your office starts private. No OpenAI or Anthropic API key is needed.

3. Start coding

Open your office and start a task in your coding app. Its agents appear as they work. Activity from before the connection is not replayed.

Browser didn’t open? Ask your coding agent “connect tinyAGENTS”. The plugin’s setup skill gives you the browser link and checks the connection. Links last 15 minutes. The plugin won’t repeatedly open tabs if you dismiss one; asking to connect starts a fresh attempt.

Already installed? Update once

Browser connection starts with plugin 0.6.0. Your current connection is preserved.

Codex

codex plugin marketplace upgrade tinyagents
codex plugin add sidequest-office@tinyagents

Claude Code

claude plugin marketplace update tinyagents
claude plugin update sidequest-office@tinyagents --scope user

Restart the app and review its hooks when asked. The technical plugin name remains sidequest-office so existing installations continue to work.

One office, both coding clients

Install both plugins and pair once. They read the same ~/.sidequest/config.json. On additional computers, inside WSL, containers or SSH, connect through the browser with the same GitHub/GitLab account. On headless machines, ask the setup skill for the connection link. Node must be installed where the client runs. Each client keeps its own people and sessions in your office.

A project is identified by its Git origin, not its name. Codex and Claude working on the same repository appear in the same project. Subfolders, worktrees and SSH/HTTPS clones of that origin group together. Different repositories with the same name stay separate. Without a Git remote, the observer uses the Git common folder; without Git, it uses the real folder path. Only a fingerprint leaves your computer.

To group folders with different remotes, add overrides to your existing connection file. Keep its existing connection fields. Use forward slashes in folder paths:

"projects": {
  "C:/work/shop-web": {
    "projectId": "our-shop",
    "projectName": "Shop",
    "vertical": "commerce",
    "projectDescription": "A shop for unusually ambitious houseplants."
  },
  "C:/work/shop-api": {
    "projectId": "our-shop",
    "projectName": "Shop"
  }
}

Overrides also apply to subfolders. On macOS/Linux, use paths such as /Users/you/work/shop. Changing a repo's origin or upgrading an older observer can leave an old room visible as away; existing history is not migrated.

Room signs and character badges

Click a room sign or project in the left rail to open its directory. Add a brief with Edit room brief and select a vertical with Choose vertical & props. Room numbers and colors match character badges. ⌘ Codex and ✳ Claude identify the client; ★ identifies a team lead and ↳ a subagent.

Visit friends and share your office

Open Friends → Share my office, set a public name and click Open visitor link. Copy that link to share a read-only view. Project names and room briefs stay hidden unless you enable them. Task text, tool details and private history are always excluded. Close the link there at any time.

Paste someone else's visitor link into Friends → Add friend. Choose Visit, or check In my world and Show my neighborhood. Up to three offices can share your café, arcade and meeting areas, with up to 24 characters per friend. Visit an office to see its full cast.

Start a coffee summit, rubber-duck debate, competitive stand-up or arcade rivalry. Characters between tasks take part. These are playful animations in your view; they do not send messages, control agents, or synchronize antics into your friend's browser. Friends and private room edits are stored in this browser. Publish again to update your public room designs.

Sign in, manage connections, or delete your office

Sign into the same GitHub or GitLab account on any computer. Under My account & agents, see or remove connected computers. Install the plugin on another computer and sign in with the same account to connect it. This does not disconnect your other computers. Under Sign-in & account, link another provider, sign out, or permanently delete the account and office.

Older offices with recovery files

Use Connect agents → Open office and load your recovery file to open it in another browser. Use Manage to replace all keys or permanently delete the office. After replacing keys, save the new files and pair your clients again.

Someone with only a viewer key can watch the office but cannot replace keys or delete it. Never share the recovery or connection file publicly.

Advanced setup and diagnostics

Ask the installed agent to diagnose tinyAGENTS, or run these from its plugin folder:

node scripts/office.mjs connect
node scripts/office.mjs doctor
node scripts/office.mjs flush

For self-hosting, set TINYAGENTS_URL to your HTTPS website origin. Manual JSON import remains available under My account & agents → Advanced: manual connection file. Import with node scripts/setup.mjs /absolute/path/to/tinyagents.config.json.

If your connection drops

node scripts/office.mjs flush

This retries saved activity. For automatic retries while a terminal stays open, run node scripts/office.mjs watch; Ctrl+C stops it. The plugins also retry on each new hook.

This is a public beta distributed through a GitHub marketplace. Locally running Codex/Claude sessions are supported; cloud-orchestrated Codex sessions cannot execute these local hooks. The office mirrors observed events; animations are playful interpretations. You still approve tools and answer agents in the coding client.
