Give your agents an office.

A few commands connect Codex and Claude Code. Anyone can create an office. Only people with your keys can see its activity.

1. Save your two files

In the office, click Connect agents → New office → Create my office. Download the recovery file and connection file. Keep both private. The recovery file is your way back in; there is no email reset.

2. Pair your computer

You need Node.js 22.18 or newer and Git. Open a terminal and run:

git clone https://github.com/michaelraim/tinyagents.git
cd tinyagents

If you already have the project, open a terminal in that folder instead.

Windows PowerShell

node bridge/setup.mjs "$env:USERPROFILE/Downloads/sidequest.config.json"
node bridge/office.mjs doctor

macOS or Linux

node bridge/setup.mjs "$HOME/Downloads/sidequest.config.json"
node bridge/office.mjs doctor

Change the file path if you saved it somewhere else. Look for Ingest credentials accepted. You do not need to run a local web server or install this project's npm dependencies just to connect.

3. Install in your coding client

Codex

codex plugin marketplace add michaelraim/tinyagents
codex plugin add sidequest-office@tinyagents

Restart Codex. Enable the plugin and review/trust its hooks in /hooks. If your Codex version has no plugin commands, update it or open this repository in the desktop app and look for Tinyagents in its plugin directory.

Claude Code

claude plugin marketplace add michaelraim/tinyagents
claude plugin install sidequest-office@tinyagents --scope user

Restart Claude Code and check /hooks. Install both if you use both; they share the same office connection.

4. Start a task

Ask a connected agent to read a file or run a test in one of your projects. Its room and coworker should appear within a few seconds. Start another project or subagent to see the office grow.

Empty office? Run node bridge/office.mjs doctor. Check that Node is on your coding client's PATH and that its hooks are enabled and trusted. A client running inside WSL or on another machine needs pairing in that environment. This observer supports locally running Codex/Claude sessions; cloud-orchestrated Codex sessions cannot run these local hooks.

Open, recover, or delete your office

Use Connect agents → Open office and load your recovery file to open it in another browser. Use Manage to replace all keys or permanently delete the office. After replacing keys, save the new files and pair your clients again.

Someone with only a viewer key can watch the office but cannot replace keys or delete it. Never share the recovery or connection file publicly.

If your connection drops

node bridge/office.mjs flush

This retries saved activity. For automatic retries while a terminal stays open, run node bridge/office.mjs watch; Ctrl+C stops it. The plugins also retry on each new hook.

This is a public beta. The office mirrors observed events; animations are playful interpretations. You still approve tools and answer agents in the coding client.
